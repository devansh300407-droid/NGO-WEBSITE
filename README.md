# BetterTogether – NGO and Social Welfare Website

## 1. Project Overview

BetterTogether is a responsive NGO and Social Welfare Website developed to promote social welfare activities and encourage people to participate in community development.

The website focuses on education, healthcare, environmental protection, and community welfare. It provides information about the organization's causes and encourages visitors to volunteer and support social initiatives.

## 2. Objectives

- To spread awareness about social welfare initiatives.
- To promote education and healthcare for everyone.
- To encourage environmental protection.
- To motivate people to participate in volunteering activities.
- To create a user-friendly and responsive website.

## 3. Technologies Used

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used for styling, layouts, colors, animations, and responsive design.

## 4. Features

- Responsive navigation bar.
- Attractive homepage with a hero section.
- Social impact statistics section.
- Causes section displaying different NGO activities.
- About Us section describing the organization's mission.
- Contact form for volunteer enquiries.
- Hover effects and smooth scrolling.
- Responsive layout for desktop, tablet, and mobile screens.

## 5. Website Sections

1. **Home:** Introduction to BetterTogether.
2. **Our Impact:** Displays sample social welfare statistics.
3. **Our Causes:** Includes education, healthcare, environmental protection, and community welfare.
4. **About Us:** Explains the organization's mission and objectives.
5. **Contact:** Provides a form for visitors interested in volunteering or supporting the organization.
6. **Footer:** Contains navigation links and copyright information.

## 7. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html` and `style.css` are in the same folder.
4. Open `index.html` in any modern web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code.

An internet connection is required to load the externally hosted images.

## 8. Limitations

- The contact form is a frontend demonstration and does not send messages.
- The website does not process real donations.
- The impact statistics are sample figures used for demonstration purposes.
